# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) for the Studio SaaS Monorepo project.

## What is an ADR?

An Architecture Decision Record (ADR) is a document that captures an important architectural decision made along with its context and consequences.

## How to Use

1. Copy `0000-adr-template.md` to a new file with the next sequential number
2. Fill in the template with your decision details
3. Submit a PR for team review
4. Update status as decisions evolve
